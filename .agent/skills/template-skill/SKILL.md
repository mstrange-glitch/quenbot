# Template Skill

Skills are special instructions or tools created for a specific domain or repository. By creating a `SKILL.md` inside a folder (e.g., `.agent/skills/template-skill/`), you give the AI access to specific context or patterns to follow.

## When to Use
- Whenever you need standard boilerplate applied.
- When performing routine repository maintenance.

## Instructions
1. Always follow the project's coding style guidelines when implementing.
2. Add any helper scripts you might need into this folder alongside `SKILL.md`.
